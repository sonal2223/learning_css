# 🎨 CSS Learning Repository

A collection of **HTML and CSS practice programs** created to learn and understand CSS concepts through hands-on examples. This repository covers basic styling as well as advanced CSS features such as Flexbox, animations, transitions, positioning, responsive design, and selectors.

## 📌 Overview

This project contains multiple standalone HTML files, each focusing on a specific CSS concept. The examples are designed to make CSS concepts easier to understand by implementing them practically.

## ✨ Topics Covered

* CSS Types
* Class and ID Selectors
* Text Formatting
* Font Formatting
* Backgrounds and Background Images
* Border Properties
* Box Model
* Shadows
* Positioning
* Z-Index
* Flexbox
* Pseudo Selectors
* Transform
* Transition
* Animations
* Media Queries
* Responsive Design
* Product Card Styling
* Image Styling

## 🎯 Learning Objectives

The main purpose of this repository is to gain practical knowledge of CSS by:

* Understanding CSS syntax and structure
* Applying selectors and properties
* Creating responsive layouts
* Working with Flexbox
* Designing elements using the Box Model
* Implementing animations and transitions
* Using positioning and z-index
* Creating interactive hover effects
* Working with media queries
* Styling images, text, and product components

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/sonal2223/learning_css.git
```

2. Open the project in **VS Code**.

3. Open any `.html` file in a browser.

4. For better development, use the **Live Server** extension in VS Code.
